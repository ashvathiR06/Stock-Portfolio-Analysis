# 📊 Stock Portfolio Analyzer – Excel Project

## 📌 Project Overview

This project is an Excel-based Stock Portfolio Analyzer designed to track and analyze an investment portfolio.

The dashboard provides an overview of portfolio value, investment amount, profit/loss, returns, stock allocation, and individual stock performance.

## 📈 Features

* Live stock price tracking
* Total investment calculation
* Current portfolio value
* Profit/Loss calculation
* Individual stock return %
* Top Gainer and Top Loser identification
* Stock-wise portfolio analysis
* Sector classification
* Portfolio allocation analysis
* Excel dashboard and charts
